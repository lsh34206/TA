# backend

NestJS 기반 API 서버입니다. 실행 방법, 아키텍처, 데이터 구조는 저장소 루트의 [README.md](../README.md)와 [docs/](../docs)를 보세요.

```bash
npm install
cp .env.example .env     # Windows PowerShell: Copy-Item .env.example .env
npm run start:dev        # http://localhost:3000/api
npm test                 # 단위 테스트
npm run test:e2e         # 전체 흐름 테스트
```
